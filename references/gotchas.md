# Gotchas — 孤独症教育与国际合作真实坑位库

> 只写模型猜不到的：法规条款、称谓规范、证伪结论、工具版权。

## 1. 称谓规范
- 官方语境用**“孤独症”**（卫健委/教育部文件、残联体系）；“自闭症”是民间与港台译法；DSM-5/ICD-11 语境用 ASD/孤独症谱系障碍。
- 贬损性旧称（自闭儿等）在正式文件与对外材料中禁用。

## 2. 儿童数据 = 敏感个人信息
- 个保法第 28 条：不满十四周岁未成年人个人信息**一律属敏感个人信息**，特殊需要儿童信息双重敏感。处理须单独同意+充分必要性论证。
- 案例传播：脱敏（化名/模糊影像/去学校名）+ 监护人书面同意，两者缺一即侵权。
- 国际合作涉儿童数据出境：落入数据出境三路径（安全评估/标准合同/认证）之一，10 万人以下非敏感豁免不适用于儿童敏感信息场景。

## 3. 医教边界
- 诊断权在医疗机构（精神科/儿童保健科医师）；教育机构做的是**教育评估**（如课程本位评估），不是医学诊断。宣传“机构出诊断”属超范围经营。
- "医教结合"中教育侧职责：转介建议、教育安置、支持性干预——不含药物与临床治疗决策。

## 4. 筛查与干预工具
- M-CHAT-R/F、ADOS-2、VB-MAPP 等工具有版权与本土化常模问题：自译版本无中国常模，筛查结果无效力；采购正版与培训认证是前提。
- 干预方法循证分级（NPDC/NCA 报告口径）：ABA/早期介入丹佛模式有较高证据等级；**辅助沟通（FC）与快速提示法已被系统性证伪**（消息来源为沟通障碍学会等立场声明），市场上仍在销售，推荐即专业失范。

## 5. 政策与资源口径
- 三期特殊教育提升计划（2014-2026）是政策主线；“随班就读”资源教师配比、生均经费标准各省不同，方案引用须标注属地版本。
- 义务教育阶段“零拒绝”原则与入学评估衔接：拒收证据留存是家长端关键动作（本技能国际合作场景常见咨询点）。

## 时效声明

本坑位库基于公开法规与案例整理（截至 2026-08），法规调整频繁，执行前以主管部门当日有效文件为准。技能输出为方法论框架，不构成法律意见。
